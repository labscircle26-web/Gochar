Implement complete OCR (Optical Character Recognition) support in the Gochar app's Developer → PDF Library section.

Requirements

1. When a PDF is uploaded, automatically detect whether it contains selectable digital text or scanned/image-based pages.
2. If digital text exists, extract it directly without OCR.
3. If the PDF is scanned or contains image-based pages, automatically run OCR to recognize and extract text.
4. Support Hindi, English, and Sanskrit (including Devanagari script).
5. Preserve page numbers, chapter headings, paragraphs, tables, Sanskrit shlokas, and planetary terminology as accurately as possible.
6. Store extracted text in the database, linked to the original PDF.
7. Show processing status:
   - Uploaded
   - Extracting text
   - OCR processing
   - Completed
   - Failed
8. Add a Retry OCR option for failed documents.
9. Allow developers to preview extracted text and search within it.
10. Ensure large PDFs are processed in the background without blocking the application.

Integration with Astrology AI

Make the extracted PDF content accessible to both:

- Prediction Reader Bot
- Prediction Maker Bot

Bots must be able to retrieve relevant passages from uploaded astrology books, with source PDF name and page number citations.

Technical requirements

- Prefer native PDF text extraction first.
- Use a reliable OCR engine such as Google Cloud Vision or Tesseract.
- Avoid running OCR repeatedly on already processed pages.
- Handle large PDFs efficiently through background jobs and page-by-page processing.
- Keep original PDFs unchanged.
- Maintain secure developer-only upload and management permissions.

Important: First inspect the existing application architecture, database, PDF upload system, and Developer section. Integrate OCR into the existing system rather than creating a separate or duplicate PDF library. Preserve all existing features and functionality.

After implementation, test with both a text-based PDF and a scanned astrology PDF. Verify that the extracted content is actually accessible to both AI bots.
